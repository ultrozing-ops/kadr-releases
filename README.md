# КАДР — готовые сборки
Редактор видеокадров SVG, Структура, песочница и паспорта. Бета-версия.
## Первая установка
[Скачать полную сборку 0.112](https://github.com/ultrozing-ops/kadr-releases/releases/tag/v0.112). В Assets выберите ZIP `KADR-0.112-…zip`, распакуйте целиком и запустите `KADR.exe`. Папка `Программа` должна оставаться рядом.
## Обновления
В установленной программе нажмите слева снизу **«Проверить наличие обновления»**. Приложение проверит подпись, сохранит рабочие правки и перезапустится. Предыдущая сборка остаётся для отката.
[Описание последнего выпуска](https://github.com/ultrozing-ops/kadr-releases/releases/latest). Пакеты `KADR-update-…zip` предназначены для обновления существующей установки; их не нужно распаковывать вместо полной сборки.
Источник в настройках КАДР 0.112 и новее:
`https://github.com/ultrozing-ops/kadr-releases/releases/latest/download`
`latest.json` — служебный подписанный указатель версии. Запускать его вручную не нужно.
