# КАДР — готовые сборки
Графический редактор видеокадров SVG, работа со Структурой, песочницей и паспортами. Бета-версия.
## Скачать
[Открыть последний релиз и скачать ZIP](https://github.com/ultrozing-ops/kadr-releases/releases/latest). В разделе **Assets** выберите архив `KADR-…zip`.
1. Распакуйте ZIP целиком в отдельную папку.
2. Запустите `KADR.exe`. Папка `Программа` должна оставаться рядом.
3. Следующие версии устанавливайте кнопкой **«Проверить наличие обновления»** слева снизу.
Приложение проверяет подпись сборки, сохраняет рабочие изменения и перезапускается. Предыдущая сборка остаётся для отката.
## Источник обновлений
Для сборок с поддержкой обновлений в настройках можно указать:
`https://github.com/ultrozing-ops/kadr-releases/releases/latest/download`
Файл `latest.json` — служебный подписанный указатель версии. Вручную запускать его не нужно.
